# ฐานข้อมูลและการเก็บเวลา

## Question

ใช้ฐานข้อมูลอะไร เก็บเวลาอย่างไร และจะบังคับกฎ "จับเวลาได้ทีละอัน" ที่ชั้นไหน

## Answer

- ฐานข้อมูลคือ **PostgreSQL** (เดิมตกลง SQL Server แล้วเปลี่ยนใจ) ตามกฎ database-first: ผู้ใช้สร้าง DB เอง ผมร่างสคริปต์ให้รีวิวและรันเอง ไม่รันเอง
- เก็บเวลาเป็น **UTC** (`timestamptz`) แสดงตามเขตเวลาของเบราว์เซอร์ และจัดกลุ่มตาม "วัน" ท้องถิ่นของผู้ใช้
- **ไม่ใช้ unique filtered index** (เคยเสนอและตกลงไว้ แล้วผู้ใช้ตัดออก) บังคับกฎ "ทีละอัน" ที่ backend + ปุ่มเริ่มที่ถูกปิดเท่านั้น
- ยอมรับความเสี่ยงโดยตั้งใจ: ส่งคำขอเริ่มสองอันพร้อมกันเป๊ะ (เช่นสองแท็บ) อาจหลุดเป็นสอง Running Timer ได้
