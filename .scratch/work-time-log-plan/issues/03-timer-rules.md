# กฎของตัวจับเวลา

## Question

จับเวลาซ้อนกันได้ไหม ตัวจับเวลารอดการรีเฟรชไหม และถ้าลืมกดหยุดจะทำอย่างไร

## Answer

- จับเวลาได้ **ทีละอัน** ปุ่มเริ่มถูกปิดขณะมี Running Timer และ backend ปฏิเสธการเริ่มซ้อน
- ตัวจับเวลา **เดินต่อ** หลังรีเฟรชหรือปิดแท็บ เก็บ `started_at` ใน DB แล้วคำนวณเวลาที่ผ่านไปจากนาฬิกา ไม่นับ tick ฝั่ง client
- เวลาเริ่ม/หยุดใช้นาฬิกาของ server เป็นหลัก
- ลืมกดหยุด: **ไม่มีกลไกอัตโนมัติใน v1** ผู้ใช้หยุดเองแล้วลบรายการที่ยาวผิดปกติได้
