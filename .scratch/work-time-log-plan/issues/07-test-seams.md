# จุดทดสอบ (seam)

## Question

จะทดสอบที่จุดไหนบ้าง

## Answer

ใช้ 2 seam ระดับสูงสุดของแต่ละฝั่ง:

1. **HTTP API ของ backend** — xUnit ยิง endpoint จริงกับ PostgreSQL ทดสอบ (เริ่ม/หยุด, ห้ามเริ่มซ้อน, ชื่อว่าง/ยาวเกิน, ลบ, list ตามช่วงรวมรายการที่คร่อมขอบช่วง)
2. **ฟังก์ชันคำนวณไทม์ไลน์ของ frontend** — Jest (ตัดบล็อกตามวัน, ยอดรวม, ขอบสัปดาห์เริ่มวันอาทิตย์, แปลง UTC เป็นวันท้องถิ่น, ตำแหน่ง/ความกว้างบล็อก)

ไม่ทดสอบ: พฤติกรรม framework, ไลบรารีภายนอก, การ render HTML/CSS
