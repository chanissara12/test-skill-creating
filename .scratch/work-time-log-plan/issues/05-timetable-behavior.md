# พฤติกรรมของตารางเวลา (ไทม์ไลน์รายสัปดาห์)

## Question

หน้าประวัติแสดงอย่างไร ดูได้ละเอียดแค่ไหน และแก้ไข/ลบอะไรได้

## Answer

- เป็น **ตารางไทม์ไลน์รายสัปดาห์** (ไม่ใช่รายการ) หน้าเดียว ไม่มี routing ส่วนบนคือช่องกรอกชื่อ + ปุ่มเริ่ม/หยุด + เวลาที่เดิน ส่วนล่างคือตาราง
- สัปดาห์เริ่ม **วันอาทิตย์** มีปุ่ม ก่อนหน้า / ถัดไป / สัปดาห์นี้
- แกนเวลา **24 ชั่วโมง เลื่อนได้** ตอนเปิดหน้าเลื่อนไปที่เวลาปัจจุบัน
- บล็อกคร่อมเที่ยงคืน **ตัดตามเส้นวัน** โผล่ทั้งสองวัน ยอดรวมแต่ละวันนับเฉพาะส่วนที่อยู่ในวันนั้น (DB ยังเป็นหนึ่งแถว)
- บล็อกสั้นมากมีความกว้างขั้นต่ำ และดูรายละเอียดเต็มได้ตอนวางเมาส์/กด
- Running Timer แสดงเป็นบล็อกขอบประที่ยืดขึ้นทุกวินาที
- แสดงยอดรวมต่อวันและยอดรวมทั้งสัปดาห์
- **ลบได้** (กดบล็อกแล้วเห็นรายละเอียด + ปุ่มลบ) โดยมีกล่องยืนยัน ลบ Running Timer ไม่ได้จนกว่าจะหยุด
- ไม่มี: แก้ไข, ค้นหา, export, มุมมองอื่น
- **เดสก์ท็อปเท่านั้น** ไม่ทำเลย์เอาต์มือถือ
