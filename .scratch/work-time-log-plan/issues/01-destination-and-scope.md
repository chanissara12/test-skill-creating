# ปลายทางและขอบเขต

## Question

แผนที่นี้ต้องไปจบที่อะไร ใครเป็นผู้ใช้ และต้องรันที่ไหน

## Answer

- ปลายทางคือ spec เดียว + tickets ที่พร้อมให้ `implement` ลงมือต่อ (แอปเล็ก ขอบเขตชัด)
- ใช้คนเดียว ไม่มี login ไม่มีบัญชีผู้ใช้
- รันบนเครื่องตัวเองเท่านั้น การ deploy อยู่นอกขอบเขต
