# Work Time Log

A single-user app for recording what work was done and how long it took: enter what you are working on, start a timer, and the record is saved when the timer stops.

## Language

**Time Entry**:
A saved record of one piece of work, with a title, a start time, and a stop time.
_Avoid_: Log, session, record

**Week**:
Seven consecutive days from Sunday to Saturday, shown together as one timetable of Time Entries.
_Avoid_: Period, range

**Running Timer**:
A Time Entry that has been started but not yet stopped.
_Avoid_: Active session, open log
